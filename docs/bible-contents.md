# Bible contents, for pasting

When entering a Bible, paste the list below into the edition's contents box. Each line becomes one work in the contents, in this order, so the Bible's books can be searched, dated and cited one by one. Lines with no author dash create anonymous works; the authors and original dates can be added later from the "needs original date" filter.

The Protestant canon has 66 books. For a Bible with the Apocrypha, paste the second list after the first.
