# Decisions: Laptop tools: backup and the Logos importer

Moved word for word from `HOW_IT_WORKS.md` on 10 November 2026, in their original order (oldest first). Add new decisions on this topic at the end, in the same form: a bold title with the date, then the choice and the reason.

- **loci-backup and loci-sizes (2026-11-10).** Both read the laptop's `config.json` in the tools folder (the data repository's folder and the backup folder), which is never committed. The daily run pulls, fills catalog heights, rebuilds `catalog.json` only when a record changed (so a quiet day makes no commit for the catalog), mirrors changed files by size and time, saves a monthly snapshot of the exports and the HTML catalog, and makes one commit of what it changed. The mirror never deletes: a file missing from the repository stays in the backup, since records are never deleted anyway and a lost picture is better kept. `catalog.json` carries no precomputed search text: the app builds it just after the first screen appears (decision of 2026-11-09), so storing it would only double the file.
- **The HTML catalog uses the browser's own colors (2026-11-10).** `catalog.html` is a backup file, not part of the app, and must open on its own anywhere; it uses the system colors `Canvas` and `CanvasText` (light or dark as the reader's device), so no color is hard-coded and the app's design tokens are not needed.
- **The Logos importer, before a real export (2026-11-10).** Jakob's sample export (`inputs/logos-sample.csv`, build step 4.4) has not arrived, so the importer was built and tested with a small made-up export, and the column names Logos uses are a first reading kept in one table (`columns.mjs`, also in the tools README). It accepts commas or tabs, UTF-8 or UTF-16, and "Surname, Given" names. Steps 11.1 to 11.4 stay unticked until it is run on the real file.
- **"Edited in Loci" for Logos fields (2026-11-10).** Every record notes when each field was last edited, but not by whom, so the importer keeps what it last wrote for each resource in `integrations/logos-import.json`. A field still holding that value is the importer's to update; any other value was set by a person and is left alone. The file is in the data repository, so a second laptop sees the same thing.
- **Logos links and covers (2026-11-10).** Suggested links to existing works are listed in a text file on the laptop, each to be changed from "no" to "yes" by a person and confirmed with `--confirm-links`; nothing is linked automatically. Logos covers come from Open Library by ISBN into `images/inbox/`, in batches that carry on where they stopped. The laptop covers page now saves each cover into the app's catalog on the laptop (the same browser, so the same stored catalog), and the app sends it with its next sync; inbox covers are marked as coming from Open Library. Books with no cover keep the app's drawn cover, which already shows the title and author like a citation, so no separate "tile description" is stored.
- **The real Logos export (2026-11-10, build step 4.4).** Jakob exported a collection of 53 resources (from Logos's Collections menu) as CSV: UTF-8 with a byte-order mark, 24 columns: Resource ID, Metadata Version, Metadata Language, Title, Logos Title, Abbreviated Title, Logos Abbreviated Title, Resource Type, Edition, Authors, My Tags, Community Tags, My Rating, Community Rating, Publishers, Publication Date, Electronic Publication Date, Series, Subjects, Languages, File Name, File Version, Last Updated, License. What it changed in the importer:
  - The publisher column is "Publishers". There is no Subtitle column (the subtitle follows the title's first colon, and is split off there) and no ISBN column.
  - Publication dates include "1884–1885", "1993 [2008]" and "n.d."; the first year is taken, and "n.d." is no year.
  - Authors are "Surname, Given" names separated by ";", and include editors (Philip Schaff, for one); the export does not tell them apart, so all are imported as authors and can be corrected in the app.
  - Five columns change with every export without the book changing (Metadata Version, File Version, Last Updated, Community Rating, Community Tags). Keeping them would make every book look edited on every import, so they are left out of the extra Logos data; every other column is kept, including License (Permanent or Temporary) and Subjects.
  - Without an ISBN, covers are found on Open Library by title and first author, and taken only when Open Library's title is the same; in the trial 1 of 8 was found, and the rest keep the app's drawn cover.
  - A Logos book is suggested as the same work as one in the catalog only when the authors agree, or neither has one: the trial suggested eight Romans commentaries as the Epistle to the Romans (a work with no author) until this was added.
