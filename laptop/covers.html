Covers

A laptop page, never loaded by phones. It turns covers into the app's two sizes with the same code the phone uses for photos.

Covers from the inbox

Choose the pictures in images/inbox/ of the data repository (laptop tools save covers there, named by the edition's ID: <edition id>.jpg). Each is made into a thumbnail and a detail image, and its main color is found.

Writing the results into the data repository arrives with sync (build plan phase 7); until then this page shows what would be saved.
